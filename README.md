# Focus Flow — pomodoro timer with session journal

A single-file installable PWA (index.html inline CSS/JS, manifest.json, sw.js): a pomodoro-style focus timer with configurable work/break lengths, a large glanceable countdown, gentle WebAudio chimes (no audio files), a session journal (what you worked on, stored in localStorage), daily totals, and a weekly streak view. Screen Wake Lock API when available so the timer stays visible. Fully offline, no external requests. The deliverable is the complete index.html, manifest.json, and sw.js source.
